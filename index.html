        Free sources only, no keys: Wikipedia, Wikidata, DuckDuckGo, Bing, Mojeek, Google News, Hacker News, Stack Exchange, Reddit, Crossref, Open Library, GitHub and arXiv, plus public page readers and CORS proxies.
